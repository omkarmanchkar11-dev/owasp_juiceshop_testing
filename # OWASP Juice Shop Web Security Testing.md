# OWASP Juice Shop Web Security Testing

## Objective
To understand basic web application security testing using OWASP Juice Shop and Burp Suite.

## Tools Used
- Burp Suite Community Edition
- Docker
- OWASP Juice Shop
- macOS

## Activities Performed
- Installed and configured Burp Suite proxy
- Deployed OWASP Juice Shop locally using Docker
- Intercepted HTTP traffic
- Analyzed GET requests and HTTP headers
- Used Repeater to resend requests manually

## Key Learning
- Understanding HTTP requests and responses
- Basic proxy interception
- Web application traffic analysis
- Request replay using Burp Repeater
